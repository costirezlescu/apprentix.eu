Reuse this data

Everything the site shows is also available as files: each indicator as CSV and JSON with provenance (index), each dataset as JSON, and the whole collection described in a Frictionless data package. Please cite the original publisher named on each item, and Apprentix (CITATION.cff).

How to read the data

The official source is authoritative. Where this site and the source differ, the source is right. Records here are condensed for comparison and omit detail that the original carries.

Categories are interpretations. Filters such as “mostly at work” group records so they can be compared. The grouping is ours, not the publisher's, unless stated otherwise in the dataset notes above.

Dates matter. Each dataset records when it was retrieved. Sources are updated on their own cycles, and this site may lag behind.

Reuse

The code of this site is MIT-licensed and free to reuse. The data belongs to its original publishers and is not covered by that licence. Each source's terms are listed above and on every indicator; most European sources here are CC BY 4.0 or allow reproduction with acknowledgement.

Corrections

If a record misrepresents its source, it will be corrected or removed. Please report it.
