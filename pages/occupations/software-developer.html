Want to be a software developer?

Software developers implement or program all kinds of software systems based on specifications and designs by using programming languages, tools, and platforms. Below: every qualification for a software developer that 14 European countries publish to Europass, at which level, and where to look for an apprenticeship.

Most qualifications here are at EQF 5 (short-cycle higher VET, such as Sweden's yrkeshögskola); apprenticeships exist in Austria, Germany and France among others.

What the work involves

Software developers implement or program all kinds of software systems based on specifications and designs by using programming languages, tools, and platforms.

  • engineering processes
  • project management
  • engineering principles
  • manage engineering project
  • develop automated migration methods
  • web services
  • debug software
  • use an application-specific interface
  • identify customer requirements
  • use software design patterns
  • develop software prototype
  • tools for software configuration management

And 12 more essential skills. From ESCO, the European classification of skills and occupations: software developer (2512.4). ISCO-08 unit group 2512 “Software developers”.

How this page is made

Each occupation has 'include' and 'exclude' regular expressions, applied to the qualification's title and original-language title after lower-casing and removing accents. Patterns cover the national languages of the 14 countries that publish vocational qualifications to Europass, and were checked by hand against every match on 18 October 2026. Matching by title finds most qualifications for an occupation but not all: titles that name only a field ('Electrical engineering') or a level are missed unless listed. No match in: Serbia.

Qualifications: European Commission, Europass — Qualifications Dataset Register (European Learning Data, SPARQL endpoint), retrieved 2026-10-01; the full dataset on Apprentix. This service uses the ESCO classification of the European Commission. The matching patterns are open: data/reference/occupation-lens.json.
