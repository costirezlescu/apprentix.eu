# Open questions

Decisions for you and Cedefop. Each has a recommended default so work can start without waiting.

| # | Question | Recommended default |
|---|---|---|
| 1 | **Who owns it?** Commissioned by Cedefop, or a proposal to Cedefop? | **If a proposal:** prototypes are marked "Mock-up", don't use Cedefop's logo, and aren't circulated as if official. **If commissioned:** Communications is the editor of record. |
| 2 | **Who gets it?** | All staff in Thessaloniki and Brussels. Later options: Governing Board members, ReferNet partners, and a public weekly edition. |
| 3 | **Who is the editor?** | Someone in Communications. They need about 2 minutes a day for the 06:30 preview, and act on exceptions only. |
| 4 | **Name and masthead** | "Cedefop Daily", with "Thessaloniki · Brussels" under it |
| 5 | **Send time** | 08:00 Athens time on Cedefop working days |
| 6 | **Calendar** | Monday to Friday; three a week from mid-July to the end of August and in late December; none on Cedefop holidays. Cedefop's official holiday list is needed. |
| 7 | **Where it runs** (BLUEPRINT, section 11) | Option C for the pilot (an external build sends one email to a Cedefop-controlled list), then A or C |
| 8 | **Media monitoring:** does Cedefop have a contract, or access to EMM through the Commission? | Use it for "Cedefop in the media" and national press. Without it, "Across Europe" waits for phase 4. |
| 9 | **Access to Cedefop's own content:** the website returns 403 to scripts | Ask the web team for a feed or JSON endpoint for news, publications and events. Meanwhile, use the filtered RSS. |
| 10 | **Internal calendar:** a feed for "Today at Cedefop" | An iCal feed from Communications with public and staff-wide events only |
| 11 | **Staff news** | Only through the inbox (HR, Communications, self-submission), with opt-out. No staff list until the DPO agrees (`PEOPLE_AND_PRIVACY.md`). |
| 12 | **DPO and EUDPR** | Record of processing and a privacy statement before phase 3 |
| 13 | **AI transparency:** a colophon line? | Yes: *"Compiled automatically from the linked sources and reviewed by Communications."* No model name. Check with legal or the DPO. |
| 14 | **Which AI service is allowed** under Cedefop's rules? | An EU-region endpoint; only public text and approved announcements go to the model |
| 15 | **The taxonomy** | Align `data/topics.yaml` with the Single Programming Document and the organigramme |
| 16 | **Languages** | English; other-language sources summarised and labelled as translated |
| 17 | **The Director's coverage** | Public-role items only, with a soft cap of 3 headline appearances a week. Confirm the Director is comfortable with that. |
| 18 | **Critical coverage of Cedefop** (critical press, audit findings) | Run it factually, but it holds the edition for the editor's decision |
| 19 | **Thessaloniki box on Fridays** | Optional: selective talks and small-venue culture, following the London method; phase 6 |
| 20 | **Greek Council Presidency** (July–December 2027; verify) | Plan coverage from spring 2027 |
| 21 | **Per-reader personalisation** ("follow apprenticeships") | Not at first: one shared paper builds shared conversation. Consider it later. |
| 22 | **Tracking** | No open pixels; aggregate click counts only |
